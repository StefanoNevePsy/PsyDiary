# PsyDiary

Diario clinico dell'aula: gruppi in calendario, sedute di gruppo, individuali e con i genitori,
note sui singoli ragazzi, idee in sospeso. Editor markdown con anteprima dal vivo.

**Stato: prototipo navigabile.** I dati (inventati) restano nel browser, in IndexedDB.
Accesso con Google, cifratura e sincronizzazione su Drive arrivano nella fase 2.

```sh
npm install
npm run dev      # sviluppo
npm run build    # dist/ statico
```

Direzione di prodotto e principi di design: [PRODUCT.md](PRODUCT.md).
